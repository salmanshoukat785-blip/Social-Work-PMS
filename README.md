# Social Work Academy

An **offline** Android study app (Kotlin + Jetpack Compose, Material 3) for *Social Work for PMS*,
Paper 1 and Paper 2, with an Urdu (right-to-left) and English (left-to-right) interface.

Version `1.0.0-rc1` (release candidate: built and checked by the steps below, not yet confirmed on a phone by the author).

## What is inside
- **Notes** from the Word file "Social Work Paper 1 & 2": 37 topics (Paper 1: 15, Paper 2: 22), English and Urdu side by side,
  with search, bookmarks, text-size control and "continue where I stopped". Three topics have no notes in the Word file
  (`p1_society`, `p1_social_institutions`, `p2_methods`) and say so on screen.
- **Practice quizzes** by topic, paper or both papers; 20 / 50 / 100 questions; optional timer; optional instant feedback;
  explanations; score; history; review; retry of wrong answers; accuracy per topic.
- **Mock tests**: timed, answers shown only after submitting, question list, mark for review, result review with filters.
- **Study tools**: glossary, flashcards, personal notes per topic, PDF reader for PDFs on the phone.
- **Progress**: topic completion, quiz statistics, topics to revise, weekly activity.
- **Settings**: language, theme, text size, backup and restore (a JSON file), reset progress.
- No internet permission, no account, no ads, no tracking.

## Honest notes about the content
- The Word file has **no MCQs**. The 576 questions (280 English, 296 Urdu) are *additional practice questions*
  generated by script from the lists in the notes and checked by a script against the notes.
  A teacher has **not** reviewed them. They are labelled this way inside the app.
- The glossary (346 terms) pairs English and Urdu by their position in the notes' lists. It is a study aid, not a dictionary.
- Paper 1 English has fewer questions because some English lists in the source are run together.

## Known limitations
- Data is stored with Jetpack DataStore (not Room). It survives restarts and is included in backups.
- The PDF reader has no zoom or search.
- No Nastaliq font is bundled: Urdu uses the phone's own Urdu font.
- No daily reminders.
- No "important questions" or past-paper section (no such material was supplied).

## Build
- Upload `SocialWorkAcademy_*.zip` to the repository and the **Android Build** workflow unpacks it and builds
  the debug APK (artifact `SocialWorkAcademy-debug-apk`). See `docs/BUILD_AND_RELEASE.md`.
- Signed release APK: `docs/BUILD_AND_RELEASE.md`, section 3.
- Phone test list: `docs/OFFLINE_AND_ACCESSIBILITY_CHECKLIST.md`.
- Local: `./gradlew testDebugUnitTest assembleDebug` (JDK 17).

## Layout
- `app/src/main/java/com/socialwork/academy/data` : models, content loading, quiz engine, storage, backup
- `.../ui` and `.../ui/screens` : Compose screens and view models
- `app/src/main/assets/content` : `content.json` (notes), `mcqs.json`, `glossary.json`
- `app/src/test` : unit tests
